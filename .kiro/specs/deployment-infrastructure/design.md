## Overview

Nazar AI uses **AWS Amplify Gen 2** for infrastructure-as-code deployment. The entire stack (frontend, backend, AI services) is defined in TypeScript and deployed automatically via Git-based CI/CD. The MVP is currently deployed in ap-south-1 (Mumbai) with email-based auth, 5 DynamoDB data models, and AppSync GraphQL API.

**Deployment Architecture:**
```
Git Repository (GitHub)
  ↓ (git push)
AWS Amplify (CI/CD)
  ↓ (build & deploy)
├── Frontend: React PWA → CloudFront + S3
├── Backend: Lambda (chatbot) + AppSync + DynamoDB
├── Auth: Cognito User/Identity Pools
├── Data: DynamoDB + S3 Storage
└── AI: Bedrock Nova Micro chatbot (DEPLOYED) + Rekognition (planned)
```

**Deployment Environments:**
- **Development**: Personal sandbox (local `npx ampx sandbox`)
- **Staging**: Shared staging environment (`staging` branch → Amplify)
- **Production**: Live production (`main` branch → Amplify)

## Manual AWS Resource Setup

Some resources cannot be managed by Amplify and require manual setup:

### 1. Amazon Rekognition Custom Labels (DR Detection Model)

**Step 1: Prepare Dataset**
```bash
# Download Kaggle Diabetic Retinopathy dataset
kaggle competitions download -c diabetic-retinopathy-detection

# Preprocess images (resize to 512x512)
python scripts/preprocess_retina_images.py

# Upload to S3
aws s3 sync ./data/processed s3://diabetcare-dr-training-data/
```

**Step 2: Create Rekognition Project**
```bash
# Create project
aws rekognition create-project \
  --project-name diabetcare-dr-detection \
  --region ap-south-1

# Create dataset
aws rekognition create-dataset \
  --project-arn arn:aws:rekognition:ap-south-1:123456789012:project/diabetcare-dr-detection \
  --dataset-type TRAIN \
  --dataset-source '{
    "GroundTruthManifest": {
      "S3Object": {
        "Bucket": "diabetcare-dr-training-data",
        "Name": "train_manifest.json"
      }
    }
  }'

# Train model (takes 1-2 hours, cost: ~$10)
aws rekognition create-project-version \
  --project-arn arn:aws:rekognition:ap-south-1:123456789012:project/diabetcare-dr-detection \
  --version-name v1 \
  --output-config '{"S3Bucket":"diabetcare-dr-model-output"}'

# Wait for training to complete
aws rekognition describe-project-versions \
  --project-arn arn:aws:rekognition:ap-south-1:123456789012:project/diabetcare-dr-detection \
  --version-names v1

# Start model (2 inference units, $1/hour when running)
aws rekognition start-project-version \
  --project-version-arn arn:aws:rekognition:ap-south-1:123456789012:project/diabetcare-dr-detection/version/v1 \
  --min-inference-units 2
```

- Feature branches create preview environments (optional, can enable in Amplify Console)

### 2. Pre-Deployment Tests

**Add to amplify.yml:**
```yaml
frontend:
  phases:
    preBuild:
      commands:
        - npm ci
    build:
      commands:
        - npm run lint       # ESLint

        - npm run build      # Vite build
  artifacts:
    baseDirectory: dist
    files:
      - '**/*'
```

### 3. Post-Deployment Smoke Tests

**Create Lambda function for smoke tests:**
```python
# amplify/functions/smoke-tests/handler.py
import requests
import os

def handler(event, context):
    endpoint = os.environ['APPSYNC_ENDPOINT']

    # Test 1: Health check
    response = requests.get(f"{endpoint}/health")
    assert response.status_code == 200

    # Test 2: GraphQL introspection
    query = {"query": "{ __schema { queryType { name } } }"}
    response = requests.post(endpoint, json=query)
    assert response.status_code == 200

    return {"statusCode": 200, "body": "All smoke tests passed"}
```

**Trigger after deployment (EventBridge rule):**
```bash

  --name diabetcare-deployment-smoke-tests \
  --event-pattern '{"source":["aws.amplify"],"detail-type":["Amplify Deployment State Change"],"detail":{"appId":["YOUR_APP_ID"],"jobStatus":["SUCCEED"]}}' \
```

## Rollback Procedures

**Via Console:**
```
Amplify Console → main branch → Deployments → Select previous deployment → Redeploy
```

**Via CLI:**
```bash
# List deployments
aws amplify list-jobs \
  --app-id YOUR_APP_ID \
  --branch-name main \
  --max-results 10

# Redeploy specific job
aws amplify start-deployment \
  --app-id YOUR_APP_ID \
  --branch-name main \
  --job-id JOB_ID_TO_ROLLBACK
```

### 2. Lambda Rollback

**Publish Lambda version before deployment:**
```bash
aws lambda publish-version \
  --function-name glucose-api \
  --description "v1.2.0"
```

**Rollback to previous version:**
```bash
aws lambda update-alias \
  --function-name glucose-api \
  --name PROD \
  --function-version 3  # Previous version number
```

## Troubleshooting

### Issue 1: Amplify Build Fails

**Symptoms:** Build fails with "Module not found" error

**Solution:**
```bash
# Check amplify.yml uses npm ci (not npm install)
# Verify package-lock.json is committed to Git
git add package-lock.json
git commit -m "Add package-lock.json"
git push
```

### Issue 2: Lambda Function Timeout

**Symptoms:** API requests return 504 Gateway Timeout

**Solution:**
```typescript
// Increase Lambda timeout in amplify/functions/.../resource.ts
export const glucoseApi = defineFunction({
  name: 'glucose-api',
  entry: './handler.ts',
  timeout: 60,  // Increase from default 3s to 60s
  memoryMB: 1024,
});
```

### Issue 3: Cognito User Registration Fails

**Symptoms:** "User pool does not exist" error

**Solution:**
```bash
# Verify Cognito User Pool exists
aws cognito-idp list-user-pools --max-results 10

# Redeploy auth resource
npx ampx sandbox --profile default
```

### Issue 4: DR Detection Returns 500 Error

**Symptoms:** Rekognition inference fails

**Solution:**
```bash
# Check if Rekognition model is running
aws rekognition describe-project-versions \
  --project-arn arn:aws:rekognition:ap-south-1:123456789012:project/diabetcare-dr-detection \
  --version-names v1

# If status is STOPPED, start the model
aws rekognition start-project-version \
  --project-version-arn arn:aws:rekognition:ap-south-1:123456789012:project/diabetcare-dr-detection/version/v1 \
  --min-inference-units 2
```

### Issue 5: High AWS Costs

**Symptoms:** Monthly bill exceeds budget

**Solution:**
```bash
# Check CloudWatch Logs retention (reduce from 30 days to 7 days)
aws logs put-retention-policy \
  --log-group-name /aws/lambda/glucose-api \
  --retention-in-days 7

# Stop unused Rekognition models
```
