## 📋 How to Use These Resources

### For Clinical Research:
1. **Start with guidelines**: WHO, CDC, ADA, ICMR for evidence-based protocols
2. **Search PubMed**: Find peer-reviewed studies with specific metrics
3. **Check clinical trials**: ClinicalTrials.gov for ongoing research
4. **Verify on official sites**: Always cross-reference claims

### For AI/ML Technical Research:
1. **Search arXiv**: Latest AI research papers (include year: 2024-2026)
2. **Check Papers with Code**: Benchmarks and leaderboard results
3. **Find implementations**: GitHub for code, Hugging Face for models
4. **Review model cards**: Understand training data, limitations

### For India-Specific Context:
1. **Government statistics**: ICMR, MoHFW, NITI Aayog, Census
2. **Disease programs**: NIKSHAY (TB), NVBDCP (malaria), NACO (HIV)
3. **Digital health**: ABDM for integration, e-Sanjeevani for telemedicine
4. **Regulatory**: CDSCO for medical device classification

### For Dataset Research:
1. **Medical imaging**: Grand Challenge, Kaggle healthcare
2. **Clinical data**: PhysioNet, MIMIC (requires CITI training)
3. **Genomics**: ClinVar, UniProt, EBI
4. **Open datasets**: Search Kaggle, Papers with Code

### Citation Best Practices:
✅ **DO:**
- Use DOI links for journal papers
- Include author names (First Author et al.)
- Specify publication year
- Quote exact metrics (sensitivity, specificity, accuracy)
- Link directly to the specific article/page

❌ **DON'T:**
- Link to journal homepages instead of specific papers
- Use vague citations like "studies show" without sources
- Cite blog posts when peer-reviewed papers exist
- Use outdated sources (>2-3 years for medical/AI topics)

## 🔐 Access Notes

### Open Access:
- **Free**: WHO, CDC, NIH, PubMed abstracts, PLOS, arXiv, medRxiv, GitHub
- **Requires registration**: PhysioNet, MIMIC (free after CITI training)
- **Free for India**: Many journals offer free access to Indian institutions

### Subscription Required:
- **Paid**: NEJM, Lancet, JAMA (full articles), UpToDate
- **Institutional**: IEEE, ACM (often accessible via university VPN)

### API Access:
- **PubMed E-utilities**: Free API for programmatic access
- **ClinicalTrials.gov API**: Free clinical trial data
- **ABDM Sandbox**: Free test environment for digital health integration

## ⚠️ Important Reminders

### Verify Publication Dates:
- AI/ML papers: Prefer <2 years old
- Clinical guidelines: Prefer <3 years old
- Government statistics: Verify they're current
- Regulatory guidance: Always check latest version

### Cross-Reference Sources:
- Minimum 2 sources for medical claims
- Minimum 2 sources for AI performance metrics
- Official government sites for statistics
- Peer-reviewed journals for clinical evidence

### India-Specific Validation:
- Verify data applies to Indian population
- Check if treatments/devices are available in India
- Confirm regulatory status with CDSCO
- Validate cost estimates in INR

## 🔄 Updating This List

**When to add a new domain:**
- Peer-reviewed journal with impact factor >5
- Official government health agency
- Established research institution
- Reputable health technology news source

**When NOT to add:**
- Personal blogs or opinion sites
- Unverified health information sites
- Commercial product marketing sites
- News aggregators without original reporting

**How to add:**
1. Add to `.claude/settings.local.json` using format: `WebFetch(domain:example.com)`
2. Add to this document with description
3. Test with a WebFetch to verify access
