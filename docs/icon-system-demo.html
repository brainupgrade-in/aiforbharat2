How to Use

1. Include the SVG sprite

<!-- In your HTML head or body -->
<svg xmlns="http://www.w3.org/2000/svg" style="display: none;">
  <!-- Icon definitions from icons.svg -->
</svg>

2. Use the icon

<svg class="icon icon-md">
  <use href="images/icons.svg#icon-home"></use>
</svg>

3. Apply size and color classes

<!-- Large icon with success color -->
<svg class="icon icon-lg icon-success">
  <use href="images/icons.svg#icon-check"></use>
</svg>

ℹ️ Migration from Emoji

To migrate from emoji icons to SVG icons:

  1. Replace emoji spans with SVG elements
  2. Add appropriate aria-label to SVG for accessibility
  3. Use icon size classes (icon-sm, icon-md, icon-lg, icon-xl)
  4. Apply color classes if needed (icon-primary, icon-success, etc.)

Note: Keep emoji icons for now in the wireframes. Migrate to SVG icons in the actual React implementation for better consistency across platforms.
